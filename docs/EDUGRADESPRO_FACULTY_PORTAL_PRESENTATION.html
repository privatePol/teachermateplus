First Login

Faculty Login and First-Time Entry

What faculty do first

  • Open the Faculty Portal login page.
  • Enter assigned username and password.
  • Complete required security steps before reaching the dashboard.
  • Use forgot-password flow if access needs to be recovered.

Information available on entry

  • portal identity and NCBA branding
  • faculty-specific login route
  • privacy notice access
  • security-controlled access to classes and grading tools

Privacy and Security

Privacy Notice and Account Security

Privacy notice behavior

  • Faculty must accept the EduGradesPro Privacy Consent when required.
  • The page links to the official NCBA Data Privacy Notice.
  • Consent version, acceptance time, and related audit metadata are stored.

Security features to mention

  • forced password change support
  • login lockout after repeated failed attempts
  • single-device session behavior
  • privacy notice link available inside the portal
Privacy Consent page. Faculty review and accept privacy terms before continuing when required.

Periodic Grading

Periodic Grading Is Period-Specific

Main period tools

  • Grade Activities
  • Attendance
  • Summary
  • Prediction
  • Who Viewed

Important message for presentation

Faculty work inside the selected grading period. This keeps Prelim, Midterm, Pre-Final, and Finals work separate and easier to monitor.

Each grading period has its own tools, which helps faculty understand what records belong to the current period.
Activities and Scores

Grade Activities and Score Encoding

Grade Activities

  • faculty creates or reviews activities for the current period
  • activities follow template components such as quizzes, participation, or exam
  • each activity can lead to score encoding

Score Encoding

  • scores are encoded per student
  • computed values follow the official template logic
  • save actions keep the official gradebook updated

Attendance

Attendance Records Inside the Period Workflow

What faculty can manage

  • attendance sessions
  • student attendance status
  • period-linked attendance records
  • attendance scoring when the grading template includes attendance

Governance note

Attendance participates in grading only through configured template rules. The portal shows the attendance workspace without changing the official computation model casually.

Summary and Prediction

Summary, Printable Periodic Grades, and Prediction

Summary page

  • shows computed period summary
  • supports periodic-grade review before submission
  • includes printable periodic grades for external encoding workflows

Prediction page

  • estimates current grading-period outcome
  • uses encoded scores and assumed scores for remaining items
  • does not change actual grades
Period Summary page, used for computed periodic grade review and print output.
Prediction page, clearly scoped to the current grading period and read-only for what-if planning.

Faculty Portal Takeaway

The Faculty Portal guides teachers from secure access to class work, periodic grade encoding, computed summaries, prediction support, and submission readiness.
