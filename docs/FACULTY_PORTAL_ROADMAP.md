# EduGradesPro V1
## Faculty Portal Prioritized Roadmap

Prepared for board and academic presentation

### Goal
Strengthen the Faculty Portal so it is not only a grading encoder, but a guided academic workspace that helps teachers:

- track deadlines
- complete grades on time
- reduce submission errors
- monitor at-risk students
- comply with institutional governance

---

## 1. Immediate Priority
These items directly support faculty readiness, governance visibility, and board-facing confidence.

### 1.1 Dashboard deadline reminder
Status: Implemented

Purpose:
- remind faculty of the nearest current submission deadline
- reduce missed deadlines
- surface whether a deadline is upcoming, overdue, or not yet configured

### 1.2 Faculty KPI dashboard
Status: Implemented

Current KPI cards:
- Classes Not Yet Submitted
- Failed Students Per Periodic Grades
- Dropped Students
- Active Students Without Grades
- Periods Near Deadline
- Periods Already Submitted
- Withdrawn Students
- Activities Without Scores Yet
- Classes With Missing Grades
- Pending Correction Requests

Purpose:
- give faculty a daily operational view
- reduce hidden issues before submission
- make governance visible through simple indicators

### 1.3 Faculty help center
Status: Implemented

Current deliverables:
- faculty-facing help page linked to `?`
- formal policy/manual page for academics and management

Purpose:
- improve onboarding
- reduce repetitive support questions
- provide a governance reference for institutional review

### 1.4 Printable compact grading sheet
Status: Implemented

Purpose:
- provide a clean printout for formal review and sign-off
- keep a faculty-friendly and management-friendly paper record

---

## 2. Near-Term Priority
These are the next most useful operational enhancements.

### 2.1 Missing Grades Assistant
Purpose:
- show exactly which students and activities are still incomplete
- provide direct links to unresolved records

Expected value:
- faster completion
- fewer submission delays

### 2.2 Grade Simulator
Purpose:
- allow faculty to estimate the score a student needs to pass or reach a target grade

Expected value:
- stronger academic advising
- easier student consultation

### 2.3 At-Risk Student Monitor
Purpose:
- identify students with combinations of:
  - failing grades
  - missing scores
  - poor attendance

Expected value:
- earlier interventions
- better academic support

Recommended timing:
- Prelim: early warning
- Midterm: primary intervention period
- Pre-Final: last follow-up checkpoint
- Final: confirmation and final review

Current design:
- the faculty monitor should focus on the current active grading period when configured
- final-grade projection should remain available in the detailed prediction page, not as the main at-risk monitor table

### 2.4 Period Lock Countdown
Purpose:
- display time remaining before the current submission deadline

Expected value:
- improves urgency and self-management

### 2.5 Per-Student Grade Trail
Purpose:
- show how a student's grade was computed

Expected value:
- transparency
- easier complaint handling
- stronger trust in the system

---

### 3.1 Faculty notification center

- deadline approaching

### 3.2 Intervention tracker

- record students needing follow-up, remediation, or academic support

### 3.3 Consultation and feedback log
Purpose:
- document grade-related consultations with students

### 3.4 Teaching load intelligence
Purpose:
- show faculty workload by class size, deadline exposure, and at-risk population

### 3.5 Expanded printable record variants
Possible outputs:
- detailed class record
- compact grade sheet
