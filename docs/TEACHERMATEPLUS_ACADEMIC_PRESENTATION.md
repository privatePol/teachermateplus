## Presentation Goal

This presentation introduces **TeacherMate+** as a **template-driven, governance-aware academic grading platform** that helps the institution:

- standardize grade computation
- reduce spreadsheet dependency
- enforce academic controls
- strengthen accountability
- improve faculty workflow support

---

## Suggested Presentation Flow

Use this as a short 10-12 slide presentation.

---

## Slide 1. Title Slide

**Title:**  
TeacherMate+: Template-Driven Academic Grading and Governance Platform

**Subtitle:**  
NCBA Academic Presentation

**Presenter message:**  
TeacherMate+ is designed not only as a grade encoding system, but as a governed academic platform that standardizes grading, supports faculty, and protects institutional processes.

---

## Slide 2. What TeacherMate+ Is

**Slide content**

- Multi-tenant, multi-campus academic grading platform
- Separate Admin Portal and Faculty Portal
- Designed to centralize grading workflows
- Built to reduce operational risk from disconnected spreadsheets and manual file handling

**Presenter note**

The key idea is that TeacherMate+ is not just for encoding grades. It is a structured academic workflow system that combines computation, policy, and accountability.

---

## Slide 3. Template-Driven Grade Processing

**Slide content**

- Grades are processed through assigned **grading templates**
- Each course follows a defined computation structure
- Periodic grades and final grades are derived from approved template logic
- The system follows the same official grading path consistently across users and classes

**Main message**

TeacherMate+ is **template-driven**, which means computation is not improvised per faculty member.

**Presenter note**

Instead of each faculty member computing grades differently in separate spreadsheets, TeacherMate+ allows the institution to define the grading logic once, assign it to the course, and let the system process it consistently.

---

## Slide 4. Faculty Can Build the Grading Structure

**Slide content**

Faculty can work within the template structure using:

- **Components**
  - example: Exam, Class Standing
- **Sub-components**
  - example: Quizzes, Participation/Output
- **Details**
  - example: Recitation, Assignment, Activity

**Main message**

TeacherMate+ supports the real academic breakdown used in institutional grading practice.

**Presenter note**

The system is flexible enough to represent actual grading structures used by faculty and departments. It can go from top-level weighted components down to sub-components and detailed items, depending on how the template is configured.

---

## Slide 5. Grade Correction Governance

**Slide content**

- Faculty can file correction petitions through the system
- Correction requests may include:
  - affected students
  - affected items
  - original values
  - corrected values
- Approval routes can be governed by role and department
- Once approved, corrected values can be posted automatically and grades recomputed

**Main message**

TeacherMate+ treats grade correction as a **governed academic process**, not an informal adjustment.

**Presenter note**

This is very important for institutional trust. Corrections are not hidden edits. They are routed, reviewed, approved, and recorded. That means the institution keeps both flexibility and accountability.

---

## Slide 6. Template Management Lifecycle

**Slide content**

TeacherMate+ supports the full template lifecycle:

1. **Draft**
2. **Review**
3. **Approval**
4. **Publication**
5. **Hotfix governance for live templates**

**Main message**

Templates are managed under a formal lifecycle instead of being edited casually in production.

**Presenter note**

This is one of the strongest governance features of the platform. A grading template can be created, reviewed, approved, published, and if necessary hotfixed with auditability and role-based control.

---

## Slide 7. Governance Settings

**Slide content**

TeacherMate+ includes configurable governance settings for:

- active academic year and term
- active grading period
- grading template governance
- correction governance
- submission deadlines and period locks
- login security and lockout

**Main message**

Governance is not scattered. It is centralized and configurable.

**Presenter note**

This means the institution can decide who drafts, who reviews, who approves, who publishes, who can reopen, and how correction requests move. The system is designed to adapt to institutional policy.

## Short Talking Points Per Requested Topic

### 1. Template-Driven Grade Processing

TeacherMate+ computes grades based on approved grading templates assigned to courses. This standardizes how the system processes periodic and final grades.

### 2. Faculty Can Create Components, Sub-components, and Details

The platform supports a hierarchical grading structure that reflects real classroom grading practice, from major components down to detailed grading items.

### 3. Grade Correction Governance

Grade correction is processed through governed petitions, approval routes, and recomputation logic, instead of untracked manual editing.

### 4. Template Management

Templates move through a lifecycle of draft, review, approval, and publication, with hotfix governance for live corrections when needed.

### 5. Other Features

Faculty assignments, reminders, active grading period control, at-risk monitoring, prediction support, notes, audit logs, and security controls.

### 6. Governance Settings

The system allows governance settings for template roles, corrections, deadlines, active period control, security settings, and feature activation.

## Add-On Slide B. Active Grading Period Governance

**Slide content**

- The institution can define the **current active grading period**
- Example:
  - `Prelim`
  - `Midterm`
  - `Pre-Final`
  - `Final`
- When one period is active, other periods can be closed by policy
- Closed periods reopen only when:
  - that period becomes active
  - the class period is formally reopened
  - an approved correction window exists

**Main message**

TeacherMate+ helps enforce period discipline so faculty work is aligned with institutional grading timelines.

**Presenter note**

This feature reduces confusion and prevents premature or unauthorized work in non-active grading periods. At the same time, the system still protects legitimate exceptions such as approved reopen or correction workflows.
