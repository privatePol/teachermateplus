1. What This Portal Is For

The Faculty Portal helps faculty manage the classes officially assigned to them. Faculty can create activities, encode scores, record attendance, review summaries, submit grades, and request corrections when needed.

  • You only see classes assigned to you.
  • The portal is for grading work, not full student-record management.
  • Deadlines, reopen rules, and correction rules follow the settings configured by the school.
  • Performance and consultation pages are read-only. They explain saved grades but do not change them.
2. Who Does What
Role Primary Responsibility
Faculty Creates activities, encodes scores, records attendance, reviews summaries, submits grades, and files correction requests when needed.
Campus Admin / Dean Reviews requests, monitors deadlines, and checks grading work based on assigned permissions.
Super Admin / Operations Manages settings, security, permissions, print setup, and system-wide controls.
3. Usual Faculty Workflow
Stage What You Do Why It Matters
Class Selection Open the class assigned to you. You may also review the grading template before encoding. This keeps class access limited to the correct faculty member.
Activity Setup Create each activity under the correct grading component, subcomponent, or detail. This keeps grade computation correct.
Score Encoding Encode scores, then save. If you try to leave with unsaved scores, TeacherMate+ warns you first. Saved scores are used in grade computation. Unsaved work is not.
Summary Review Review the summary before submitting. This helps catch mistakes before grades become official.
Submission Submit only when the period records are complete and checked. Submission is the official checkpoint for that period.
Active Period Control When an active grading period is set, normal editing is allowed only in that period. Other periods are usually read-only unless reopened or covered by an approved correction window. If auto-advance is enabled, the active period moves forward after the current period deadline passes. Editing that deadline later does not move it back automatically. This prevents work in the wrong period while still allowing approved exceptions.
Active Academic Scope Classes outside the active Academic Year and Term set by admin are shown as archived/history. They are read-only for normal encoding, attendance updates, submission, self-reopen, and class-list changes. Old-term grade changes should use the governed correction workflow instead of direct editing.
Grade Book View History Use Who Viewed to see authorized admin-side openings of the gradebook monitor. Use the Quick Jump links to move between Activities, Attendance, Summary, and Who Viewed. This makes monitoring more transparent and easier to check.
4. Assignment Acceptance
Accept Before Working

A new class assignment stays pending until you accept it. While it is pending, grading and class-list actions are blocked.

Your Response Options

The pending-assignment card shows only Accept Assignment. If the load looks wrong or needs discussion, contact your campus admin or academic head before accepting.

Response Deadline

Pending assignments may have a response deadline. Reminders and expiry follow the school's configured settings.

5. Assignment Monitoring
  • Accepted assignments mean the faculty member can begin normal class work.
  • Questions or wrong-load concerns should be handled directly with admin before the faculty member accepts the load.
  • Expired assignments must be renewed or reissued by admin before the faculty member can respond again.
  • Admin users can monitor pending, due soon, accepted, and expired loads.
  • The Faculty Portal class card shows the assigned grading template. Faculty can open it in read-only mode to review formulas before grading.
  • If governance allows template issue reporting, the class grading-template page shows Report Template Issue. The report is reviewed through template hotfix governance and does not immediately change grades.
  • If a class has no active published course-template assignment, My Classes warns the faculty member that the grading template is not assigned yet and directs them to coordinate with the MIS Department.
  • If admin attached a syllabus link to the course, the accepted class card shows a syllabus icon. The link opens through TeacherMate+ assignment checks, the click is recorded for audit, then Google Drive applies the school's sharing rules.
  • Scheduled operations should run manage.py process_faculty_assignment_reminders so reminders and expirations are processed regularly.
5.1 Gradebook Essentials
Create Activities Under the Correct Area

Choose the correct grading period, component, subcomponent, or detail. Use short, clear labels such as Q1, R1, or ASSIGN-1 so the Summary remains readable.

Blank Is Missing; Zero Is a Score

A blank score is still unencoded and may block submission. Enter 0 only when the student earned zero or did not comply and school policy requires a zero.

Raw Score Base-50

Enter the actual raw score. TeacherMate+ converts it using the assigned Base-50 rule. For example, 15 out of 20 becomes 87.50.

Participation/Output Detail Averaging

Every faculty-created Participation/Output item is averaged equally. For example, Recitation 1, Recitation 2, Assignment 1, Assignment 2, Seatwork 1, and Seatwork 2 each have one equal place in the average. Faculty do not assign a separate percentage weight to each detail.

Only Created Details Are Included

If a Participation/Output detail has no faculty-created activity, it is omitted from the Summary and does not lower the average. Create only the details and activities that should be part of the period grade.

Component Weights Still Apply

Equal averaging replaces only the percentage weights of the Participation/Output details. The configured Participation/Output weight inside Class Standing and the other component or period weights still apply.

5.2 Check and Explain Grades
Review the Summary

Check the highest possible scores, activity values, averages, student statuses, and final period-grade column before submission.

Know the Average Labels

Q.AVE is Quiz Average, R.AVE is Recitation Average, P/O AVE is Participation/Output Average, and CS AVE is the weighted Class Standing Average.

Use Explain for One Student

The Explain action shows the selected student's period summary, component contributions, activity details, and exam details. Full computation rows remain available when a deeper audit is needed.

Protect Student Privacy

When the grade explanation opens, the grade table behind it is visually blocked. Close the explanation before moving to another student or allowing someone else to use the device.

Official Rounded Grade

The computed decimal grade and the official rounded grade may be different. Passing or failing follows the official grading rule used by TeacherMate+, not visual guesswork.

Correct the Source Record

The Summary and explanation are read-only. Correct an activity, score, attendance record, or allowed student status, then return to Summary to review the updated result.

6. Grade Submission
Before You Submit

Check the active students, template gaps, missing saved rows, and summary results first. TeacherMate+ blocks submission if ACTIVE students still lack required score or attendance records.

Period Snapshot

The Summary page opens Period Snapshot by default so faculty can review readiness cards before submission. This includes encoded zero scores, which are valid scores but should still be reviewed. The official Summary of Grades printout appears only after submission, so unsubmitted records are not treated as the official AIMS source.

Reopen Before the Deadline

If you submitted before the deadline, you may reopen the gradebook before the deadline, make changes, and resubmit. While reopened, Summary/Print is hidden. If the reopened gradebook reaches the deadline without resubmission, score, activity, and attendance editing are locked.

Final Page Grade Trail

The overall FINAL GRADE appears only on the Final period Summary page. That page also shows PRELIM GRADE, MIDTERM GRADE, and PRE-FINAL GRADE before the final-period grade column, such as FX Grade.

Final Grade Formula

TeacherMate+ computes the FINAL GRADE using the grading profile matched to the class. If there is no special formula, it uses all configured grading periods. Missing later periods still count in the divisor.

Deadlines

Period lock rules define submission deadlines. These deadlines are used for compliance tracking and, in some cases, locking behavior.

Read-Only Review

When a period is closed for normal encoding, Attendance and Summary may still be opened for review. Editing stays blocked unless the period is active again, reopened, or covered by an approved correction window.

Approved Reopen Request

When admin approves a reopen request after a deadline or lock, the reopen window is only 24 hours. Submit or resubmit within that window. If the window expires, the gradebook locks again and a new request is required.

Submitted After Deadline

If the gradebook is already submitted and the deadline has passed, changes must use Correction of Grades. Gradebook Reopen Request is for unsubmitted overdue or locked gradebooks only.

Final Clearance

My Classes includes a Final Clearance area. Faculty can check completion status there, but the official final clearance PDF can be printed only when all accepted course assignments in the campus-term scope are COMPLETE. Clearance includes only officially accepted course assignments.

Class Tabulation Sheet

After all active grading periods are submitted, faculty can print a full-term class tabulation sheet or legal-landscape PDF. The PDF places all period blocks and final grades across one row per student, includes the NCBA watermark, and closes the list with NOTHING FOLLOWS.

My Signature

If stored signatures are enabled, faculty can upload a PNG/JPG signature from My Signature. The current password is required before saving, replacing, or removing a signature.

Deadline Banner

The Faculty Dashboard, My Classes, and class period page show the current active grading period and submission deadline. If a deadline does not match the faculty member's campus, term, or class template period, the banner explains why it does not apply.

Dashboard Grade Status and Issues

Grade Encoding Status shows the current period status for each accepted class. Pending Grade Issues combines missing setup, missing score or attendance records, and unsubmitted gradebooks without displaying student names. Open View Performance inside a selected class for student-level attention.

Pinnacle Periodic Grade Summary

The Summary print button generates an NCBA-branded Summary of Periodic Grades for Pinnacle encoding. It includes the class details, student list, periodic grade, and status.

Class Tabulation Sheet

After all active grading periods in a class are submitted, the class period page shows Print Class Tabulation. The printed sheet includes all period activities, averages, exams, official period grades, final grades, school header, and the faculty prepared/submitted-by footer.

After Deadline

If the deadline passes or the period is locked, faculty must send a reopen request and wait for admin approval before encoding or submitting an unsubmitted gradebook.

Printed Copy

The printed sheet can be used for review, sign-off, and filing.

7. Corrections and Reopen
System Request Mode

Use the portal correction request when the school allows electronic filing and approval tracking.

Manual Only Mode

Use the paper/manual process when the school requires corrections to be handled outside the portal.

After Deadline

If an unsubmitted gradebook is locked after the deadline, use Request Gradebook Reopen and wait for approval before continuing. If it was already submitted and needs changes after the deadline, use Correction of Grades.

Audit Trail

Requests, approvals, rejections, reopen actions, gradebook changes, attachments, and correction PDFs are logged for accountability.

Notifications

If enabled, correction requests can notify approvers such as the Dean or CAO by email.

Direct Score Posting

If the request already includes exact corrected scores, final approval can post those scores directly, recompute the affected student's grades, and close the request.

7.1 Sample Grade Computation

This example shows how TeacherMate+ can compute one student's grade using Base-50 scoring, component weights, and a final-grade formula. Actual classes still follow the grading template assigned to the course.

Base-50 Raw Score Formula

Computed Score = ((Raw Score / Total Score) x 50) + 50

Blank Score Entry

A blank score remains missing and can block submission. A saved 0 is a completed score and is included in computation.

Template Coverage Before Submission

Before submission, every required non-attendance grading area must have at least one activity.

Sample Period Structure

In this sample, Prelim and Midterm use Class Standing 60% plus Exam 40%. Pre-Final uses class standing as the period grade. Final Exam uses the exam score as the period grade.

A. Prelim Sample Inputs
Area Sample Scores Computed Result
Prelim Exam 78/100 89.00
Quizzes Quiz 1: 18/20 = 95.00
Quiz 2: 15/20 = 87.50		 Quiz Average = 91.25
Recitation Recitation 1: 8/10 = 90.00
Recitation 2: 9/10 = 95.00		 Recitation Average = 92.50
Assignment Assignment 1: 18/20 = 95.00
Assignment 2: 16/20 = 90.00		 Assignment Average = 92.50
Activity Activity 1: 28/30 = 96.67
Activity 2: 25/30 = 91.67		 Activity Average = 94.17
B. Prelim Roll-Up
Step Computation Result
Participation / Output (Recitation 92.50 x 40%) + (Assignment 92.50 x 30%) + (Activity 94.17 x 30%) 93.00
Class Standing (Quizzes 91.25 x 40%) + (Participation / Output 93.00 x 60%) 92.30
Prelim Grade (Class Standing 92.30 x 60%) + (Prelim Exam 89.00 x 40%) 90.98
C. Period Results Through Finals
Period Summary of Sample Computation Period Grade
Prelim Detailed above: Class Standing 92.30 and Prelim Exam 89.00 90.98
Midterm Quiz Average 93.75, Participation / Output 92.75, Class Standing 93.15, Midterm Exam 91.00 92.29
Prefinal Quiz Average 91.25, Participation / Output 94.88, Class Standing used as Prefinal period grade 93.43
Final Exam Final Exam score 85/100 using Base-50 = 92.50 92.50
D. Final Grade
Term Rule Formula Final Grade
Regular Term (Prelim 90.98 + Midterm 92.29 + Prefinal 93.43 + Final Exam 92.50) / 4 92.30
Summer Term Example (Midterm 92.29 x 33.33%) + (Prefinal 93.43 x 33.33%) + (Final Exam 92.50 x 33.34%) 92.74
Summer computation depends on the grading profile matched to the class. If the Summer profile uses selected weighted periods, Prelim is excluded by not including it in the weight list.
7.2 Class Performance and Student Consultation
Class Performance Snapshot

Open View Performance from a selected class to see the class average, at-risk student count, missing output count, and weakest component for the chosen period.

Students Requiring Attention

The class page lists only students who are at risk, incomplete, or declining. It shows the current grade, missing outputs, trend, and primary reason without ranking students.

Explain the Current Grade

Use Explain beside Current Grade to open the same private grade explanation used in the Summary. It does not edit or save any grade.

Private Consultation View

Open the student's name to view only that student's current grade, trend, missing outputs, weakest component, and current-period breakdown. No classmates appear on this page.

Performance Trend

The consultation page uses simple line graphs and exact-value tables to show available period grades and component or subcomponent scores. If only one period is available, TeacherMate+ explains that another period is needed for a trend.

Trend Labels

AT RISK takes priority for a below-passing grade. INCOMPLETE means the student is not below passing but still has missing required outputs. Other labels are NO BASELINE, IMPROVING, DECLINING, and STABLE.

Parallel Section Comparison

Performance Trends compares only sections of the same course, academic term, and grading period handled by you. It shows section averages, risk counts, missing outputs, and weakest components using a table, simple bars, and a short rule-based message.

Read-Only and Private

Performance pages use the official grade computation service but do not create, update, submit, unlock, or store grade changes. They must not be used as a class ranking tool.

8. Grade Prediction
Unofficial and Read-Only

Grade prediction is only a guide. It does not change the official gradebook.

Same Grading Rules

Prediction uses the same grading template and formula path as the official grade computation.

Scenario Planning

When enabled, the what-if tool lets faculty test possible scores for remaining items without saving anything to the gradebook.

Feature-Governed Access

Prediction and what-if access are controlled in Configuration Management and may be limited by role.

Interpretation Guidance

The prediction page includes an explanation page for the columns, formulas, Base-50 scoring, examples, and reminders that the values are only for planning.

Passing-Final Requirement

For advanced review, the page may show what average is still needed in the remaining periods to reach a passing final grade.

Period-Specific Estimate

Each prediction page is for one grading period. The main estimate is the current-period grade. The possible final grade is only extra guidance.

Official Grade Release Control

Official grades may be hidden until the configured release point. Periodic grades may also be hidden until submission if admin enables that setting. This is separate from prediction, which is always unofficial.

8.1 Student Intervention Monitor
Purpose

The monitor lists students who may need help in the current period.

How to Use

Open it from the Faculty Portal sidebar. Start with students marked Needs Immediate Follow-up, then check Missing Requirements and Needs Monitoring.

Status Rule

The monitor uses simple statuses based on current standing, missing work, and attendance concerns.

Best Periods

Use Prelim for early warning, Midterm for the main intervention, Pre-Final for last follow-up, and Final mostly for confirmation.

Next Step

Open the class summary page to review the record and decide the next faculty follow-up.

Governance Note

This is only an advisory tool. It does not replace official grades, submission, or correction approval.

9. Student Status Rules
Status Meaning Expected Effect
ACTIVE The student is still part of the class. Included in grading, coverage, and readiness checks.
Removed from Class The student moved out of this class section but is not marked dropped or withdrawn. Excluded from this class's active grading. Faculty must use the remove icon and type remove to confirm.
DRP The student dropped this class. Excluded from active grading and readiness checks.
WITHDRAWN The student withdrew from the term. Excluded from active grading and tracked separately from dropped students.
INC The student has an incomplete class record. Excluded from active grading and readiness checks until resolved.
The class-list page shows a Status Legend so faculty can quickly check what ACTIVE, DRP, WITHDRAWN, and INC mean.
Faculty DRP changes follow the cutoff configured by Admin. By default, DRP is allowed through Pre-Final and blocked once Final is the active grading period.
When adding a student, faculty can search by student number, last name, or first name before clicking Save.
For easier checking, the class list shows a line number before the student number and formats names as LAST NAME, First Name.
10. Privacy, Security, and Audit
  • Faculty can access only assigned classes and allowed portal functions.
  • Password rules, OTP, forced password change, privacy consent, one-session login control, session timeout, and lockout are controlled by system settings.
  • Incorrect Faculty Portal passwords keep the user on the public welcome page and show the sign-in error beside the login form.
  • The Faculty Portal quick tour is only a guide. Faculty may turn it off for their next login.
  • Important actions may be audited, including submission, reopen, correction, and gradebook changes.
  • Printed or exported records must be handled according to school data privacy rules.
  • The official privacy reference is the institutional privacy notice.
Official reference: NCBA Data Privacy Notice

12. Reminder Center and Email Queue
Reminder Center

Faculty can create activity reminders, due-date reminders, and follow-up notes in one place. Future-dated activities can also create preparation reminders.

Completion and Snooze

Reminders can be marked done or snoozed so the list stays useful.

Optional Email Queue

If enabled, due reminders can send email notifications to the faculty member's registered email address.

Performance Safeguard

Email reminders are queued and processed in batches, so normal page loading stays fast.

Submission Compliance Notices

If enabled, the Reminder Center can show overdue-submission notices. These stay visible until the affected period is submitted and resolved.

13. Faculty Notes / Private Memo
Private to Faculty

Faculty notes are private memos. Students cannot see them.

Optional Scope

A memo can be general or linked to a class or student.

Pinning and Review

Important notes can be pinned. Older notes can still be searched.

Recommended Use

Use private memos for intervention reminders, schedule concerns, make-up work notes, and other faculty-only follow-up items.
