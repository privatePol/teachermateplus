ACTIVE GRADING PERIOD GOVERNANCE

Faculty Work Follows the Current Active Grading Period

TeacherMate+ aligns faculty access with NCBA's active grading timeline. This helps keep class work focused on the correct academic period while still respecting approved exceptions.

How It Works

  • NCBA can define the current active grading period, such as Prelim, Midterm, Pre-Final, or Final.
  • The active period remains open for normal faculty work.
  • Non-active periods can be closed by policy so faculty do not accidentally work ahead or reopen older periods informally.
  • This keeps grading aligned with NCBA deadlines and governance expectations.

Important Exception Rules

  • A non-active period may still be opened when it is formally reopened by authorized governance actions.
  • Approved correction windows remain protected so legitimate correction processing is not blocked.
  • The goal is period discipline with controlled flexibility, not unnecessary faculty restriction.

Secure, Controlled, and Policy-Driven Grading

TeacherMate+ helps NCBA enforce grading discipline through controlled access, academic locks, and clearly defined submission rules.

Faculty can encode grades only while the grading period is open.
Closed grading periods are locked from editing.
Submitted grades cannot be changed without authorized reopening.
Reopening actions are logged for monitoring and audit.
Grade computation follows school-defined academic weights.
Access is limited by faculty assignment, campus, and department scope.

SIS INTEGRATION AND OPERATIONAL CONTINUITY

Connected Grade Records for NCBA Operations

TeacherMate+ can expose submitted periodic grades through a secured API endpoint so NCBA's authorized systems can pull validated records without manual re-encoding. This keeps NCBA grading operations connected while preserving governance controls.

How SIS API Integration Supports NCBA

  • Pull submitted periodic grades directly into NCBA's SIS through token-protected API access
  • Reduce duplicate encoding work and lower reconciliation errors
  • Apply tenant/campus/AY/term/period filters for precise data exchange
  • Consume only submitted records to avoid draft-grade leakage
  • Maintain traceability with governance-aware grading workflows

Why NCBA Uses TeacherMate+ Instead of Standalone Grade Files

Operational Area Standalone Grade Files TeacherMate+
Data ownership and continuity Grade files may be scattered across personal devices or separate folders, making continuity harder when a faculty member is unavailable. Centralized NCBA-controlled records stay available to authorized personnel for continuity and official processing.
Submission governance and deadlines Manual follow-up and weaker control points. System-enforced submission flow, lock rules, and deadline control.
Correction and reopen traceability Limited or no formal audit trail. Governed correction/reopen process with visibility and audit history.
NCBA reporting readiness Fragmented files and manual consolidation. Structured source for summary views and SIS API integration.
