Part 1: Daily Workflow

Begin here before creating activities or encoding scores.

Recommended Daily Faculty Workflow
Daily Work Rhythm

A gentle reminder that the portal is meant to support routine class work, not create pressure.

Focused Checking

Reviewing structure, scores, and summary results before submission prevents avoidable corrections later.

Faculty Assignment Acceptance Rules
  • Accept a new class assignment before using grading or class-list tools.
  • Check the response due date on the pending-assignment card.
  • The pending-assignment card shows only Accept Assignment.
  • If something is unclear or the load looks wrong, contact your campus admin or academic head before accepting.
  • If the assignment expired, wait for admin to refresh the response window.
Good routine: check pending assignments each time you log in, especially after load changes or at the start of a term.
How to Respond to a New Assignment
  1. Open My Classes.
  2. Check the Pending Faculty Assignments section.
  3. Read the course, section, schedule, and admin instructions.
  4. If an accepted class card shows a syllabus icon, open it to view the course syllabus in Google Drive using your school Google account.
  5. Open the Grading Template if you want to review the grading structure.
  6. If the load is correct, click Accept Assignment.
  7. If the load needs discussion, contact admin first. Do not accept a class that should not be assigned to you.
  8. After acceptance, grading and class-list tools become available.

Part 2: Encoding and Review

Set up activities correctly, then check attendance and summary before submission.

Creating Activities and Encoding Scores
  • Choose the Component first. Subcomponent and detail fields appear only when needed.
  • Use short activity titles so the summary and printout stay easy to read.
  • Use the Date field to keep activities in proper order.
  • Enter each student's actual Raw Score. The score cannot be higher than the activity total.
  • TeacherMate+ converts raw scores using the Base-50 formula.
  • A blank score remains missing. Enter 0 only when zero is the student's actual recorded score.
  • All created Participation/Output items are averaged equally. Recitations, assignments, seatwork, activities, and presentations do not use individual detail percentage weights.
Tip: review every value before saving. A blank is still missing; a saved 0 is complete and is included in computation.
Step-by-Step: Create Grade Activity
  1. Open My Classes and accept the assignment if it is still pending.
  2. Click Template if you want to check the grading structure first.
  3. If there is a problem with the load, send a clarification or decline note to admin.
  4. Choose the class, choose the period, then click Activities.
  5. Select Component first.
  6. Select Subcomponent only if the selected component requires it.
  7. Select Detail only if the selected subcomponent requires it.
  8. Enter a short Activity Title (ex: Q1, R1, A1, AC1).
  9. Enter the activity's correct Total Score.
  10. Set Date using the date picker.
  11. Click Save Activity.
Step-by-Step: Encode Scores
  1. From the Activities table, click Encode Scores on the target activity.
  2. Enter the actual raw score for each student. Leave the field blank only when the score is still missing.
  3. Click Save Scores.
  4. Check the Encoded count on the Activities list.
Step-by-Step: Update Existing Activity
  1. Click Edit on the activity row.
  2. Update the mapping, title, total score, or date as needed.
  3. Click Update Activity.
  4. Check the Summary again after updating.
Step-by-Step: Delete Activity
  1. Click Delete on the target activity row.
  2. Confirm deletion.
  3. Review the summary to ensure expected values after deletion.
Guardrails (Activities and Scores)
  • You cannot save scores above the allowed maximum.
  • Blank scores remain missing and may block submission. A saved zero counts as a completed score.
  • Submission is blocked until every required non-attendance grading area has at least one activity.
  • Use the Quick Jump strip to move to Attendance, Summary, or Who Viewed.
  • If the period is Submitted or Locked, normal editing is blocked.
  • During a correction window, you may edit only the approved correction items.
  • Activity deletion is blocked while an approved correction window is active.
  • If you leave the Encode Scores page with unsaved scores, TeacherMate+ warns you first.
Attendance and Summary (Step-by-Step)
Step-by-Step: Attendance
  1. Open the period card and click Attendance.
  2. Create or select an attendance session.
  3. Set attendance status per student.
  4. Click Save Attendance.
Step-by-Step: Summary Review
  1. Open the period card and click Summary.
  2. Review component grades and the period grade.
  3. Use Explain beside a visible grade in Summary or Class Performance to review the selected student's detailed computation.
  4. Check readiness cards for coverage and missing records.
  5. Use Print Grade Book for review after submission.
  6. Submit only when ready.
Private Student Consultation
  • Open a student from Class Performance to show only that student's information.
  • The Performance Trend section shows available period grades and component scores through the selected period.
  • A trend graph needs at least two grading periods. Missing records appear as unavailable values instead of invented scores.
  • The graphs are read-only and do not change, submit, or unlock grades.
Guardrails (Attendance and Summary)
  • Submitted or locked periods are read-only for normal attendance and summary work.
  • Use the Quick Jump strip to move between Attendance, Summary, and Who Viewed.
  • If a period is closed by active-period rules, Attendance and Summary stay open for review but not editing.
  • Submission is blocked if there are no encoded grade or attendance records for active students.
  • If active students still have missing records, TeacherMate+ warns you before submission.
  • Official grades follow the grading policy matched to the class.
  • The Who Viewed icon remains available even when the period is closed.
If a value looks wrong, check the activity setup, score method, total score, and class-list status before submitting.
Grade Prediction and What-If Simulation
  • Prediction is unofficial and read-only. It does not change the official gradebook.
  • It uses the same grading template and current encoded data.
  • The main estimate is for the selected period.
  • The possible final grade is only extra guidance.
  • If enabled, you may also see highest possible, lowest possible, and needed-score guidance.
  • If enabled for your role, the what-if tool lets you test possible remaining scores without saving anything.
  • Use How Prediction Works if you need the full explanation of each column and formula.
  • The Student Intervention Monitor lists students who need attention first.
  • Use it as a current-period follow-up list. It shows current standing, missing work, attendance concerns, and suggested intervention.
  • When an active grading period is set, the monitor focuses on that period.
Treat prediction as planning support only. Official grades still depend on saved scores, submission status, and approved correction actions.
How to Use the Prediction Page
  1. Open My Classes, choose the class, then open the period card.
  2. Click the Prediction icon.
  3. Open How Prediction Works if you need column explanations.
  4. Review the estimated grade, possible final grade, progress, remaining items, and status.
  5. Open the Student Intervention Monitor from the sidebar for a class-by-class follow-up list.
  6. If what-if is enabled, select a student and enter a possible remaining score percentage.
  7. Use Refresh Prediction after major score changes.

Part 3: Submission and Corrections

Use these controls only when your records are complete and policy conditions are met.

Submission Rules
  • After submission, the period becomes read-only for normal editing.
  • TeacherMate+ blocks submission if active students have no encoded grade or attendance records.
  • If ACTIVE students still have required missing records, complete the records or update the student status to DRP/WITHDRAWN/INC where appropriate.
  • If you try to leave score entry with unsaved scores, TeacherMate+ warns you first.
  • Computed periodic grades may be visible before submission when admin allows draft review visibility.
  • The official Summary of Grades printout appears only after submission.
  • On the Summary table, visible periodic grade columns appear right after Status. ACTIVE status cells stay blank; only DRP/WITHDRAWN/INC statuses are shown.
  • Use Complete Tabulation Sheet from the class period page to review the detailed activity-and-grade grid, then choose Print Official PDF. The Faculty and Admin copies use the same Legal landscape layout; wide periods continue on additional pages with student columns repeated instead of shrinking.
  • If you submitted before the deadline, you may reopen before the deadline, revise, and resubmit.
  • If you reopen before the original deadline, resubmit before that deadline. If it reaches the deadline without resubmission, editing is locked.
  • The Period Snapshot is expanded by default so you can review readiness cards, including encoded zero scores, before submission.
  • The overall FINAL GRADE appears only on the Final period Summary page, where the final-period grade column may display as FINAL EXAM or another admin-configured label.
  • Final grade follows the configured formula. If no special formula is set, all configured periods count.
  • The Current Active Grading Period banner shows the friendly campus label, active AY, term, and grading period the campus is focused on.
  • If auto-advance is enabled, the active period moves forward after the active period deadline passes. Editing that deadline later does not move it backward automatically.
  • When a non-active period is closed, Attendance and Summary remain available for read-only review.
  • The Final Clearance area lets you preview completion status. The clearance PDF can be printed only when all accepted course assignments in the campus-term scope are COMPLETE.
  • If stored signatures are enabled, use My Signature to draw and preview a signature with mouse, touch, or stylus, or keep using PNG/JPG upload. Saving, replacing, and removing require the current password.
  • After the deadline or period lock, activity creation, score encoding, and attendance updates require a reopen request.
  • After the deadline or period lock, submit a Request Gradebook Reopen and wait for admin approval before encoding or submitting an unsubmitted gradebook.
  • After admin approval, the reopen window is only 24 hours. Submit or resubmit within that window, or the gradebook locks again and you must send a new request.
  • If the gradebook is already submitted and the deadline has passed, use Correction of Grades for any needed changes.
  • Grade Encoding Status shows where each accepted class stands. Pending Grade Issues combines setup, encoding, and submission blockers without showing student names.
  • Use View Performance inside a selected class for class average, missing outputs, weakest component, and students requiring attention.
  • Always review the on-screen Summary or printed sheet before finalizing.
Grade Corrections and Reopen
System Request Mode

Use the portal correction request if your school allows online filing and approval tracking.

Manual Only Mode

Use the paper/manual process when the school requires correction approval outside the portal.

System Request Mode (SYSTEM_REQUEST)
  1. Submit period first.
  2. Open Correction Requests from the Summary or period screen.
  3. Select one or more students, or choose the entire class, then choose the affected grading items.
  4. Review the auto-loaded original values and enter only the corrected values.
  5. File the request with justification.
  6. Wait for the configured approval route, such as Area Chair to CAO or Area Chair to College Dean to CAO.
  7. After final approval, TeacherMate+ posts the approved corrected values and recomputes affected grades.
  8. No extra faculty finalize step is needed for direct score-correction petitions.
  9. If enabled, the approved request can provide an official correction PDF for registrar reference.
  10. If enabled, TeacherMate+ can email the current approver step and the final decision to the faculty requester.
Manual Mode (MANUAL_ONLY)
  1. Prepare and submit the paper correction form.
  2. Wait for approval from the required officers.
  3. Admin reopens the class period if needed.
  4. Apply the approved correction updates.
  5. Resubmit the period.
Guardrails (Corrections)
Manual-Only Schools

If the school is set to MANUAL_ONLY, portal correction requests are disabled. Follow the paper process.

After Deadline

If the period is still unsubmitted, finish encoding and submit. If it was already submitted, use the correction workflow.

Approval Route

Approval routes are configured by admin. Your school may use one-step or two-step approval.

Original vs Corrected Value

The request grid shows the current value. Enter only the replacement value.

Audit Trail

Submissions, reopen actions, correction requests, approvals, and related changes are logged.

Part 4: Class List, Account Help, and Privacy

Manage class status carefully and follow security/privacy guidance.

Class List Rules
  • ACTIVE means the student is included in grading.
  • Remove from Class is for schedule movement to another class or section.
  • DRP means the student dropped this class.
  • WITHDRAWN means the student withdrew from the term.
  • INC means the class record is incomplete.
  • By default, faculty can mark DRP through Pre-Final, but not once Final is the active grading period.
  • Class-list status affects readiness, summary results, and final grade handling.
The class list shows a Status Legend so you can quickly check the meaning of each status.
Step-by-Step: Handle Student Movement or DRP/WITHDRAWN/INC
  1. Open class -> go to Class List.
  2. Find the student row.
  3. Use the line number for easier checking.
  4. If the student only changed schedule, click the small x beside the student number and type remove to confirm.
  5. If the student dropped, withdrew, or is incomplete, use the status dropdown.
  6. Click Save Status when updating DRP/WITHDRAWN/INC.
  7. Recheck Summary readiness after status update.
Removed, DRP, WITHDRAWN, and INC students are excluded from normal active grading and readiness counts.
Faster lookup: when adding a student, search by student number, last name, or first name.
Names are formatted as LAST NAME, First Name for easier scanning.
Archived Classes Explained
  • Active Classes are your current class workload.
  • Archived Classes are older or archived offerings.
  • Archived classes are kept for review and records. They are read-only for normal encoding, attendance updates, submission, self-reopen, and class-list changes.
  • If an old class needs a grade change, use the governed correction process instead of editing the archived class directly.
How to View Archived Classes
  1. Open My Classes.
  2. Switch to the Archived tab or filter.
  3. Open a class card if review access is allowed.
If You Lost Your Password
  • Go to the Faculty Portal sign-in page and use the Forgot Password option.
  • Enter your registered faculty email address.
  • Check your inbox for the reset email.
  • If it does not arrive, check spam or junk mail.
  • If your account is temporarily locked, wait for the lockout to end or use reset if available.
  • If you still cannot reset it, contact your campus administrator or support team.
Do not share passwords or ask co-teachers for login help. Use the reset process or contact support.
User Account Security
  1. Use a strong password that meets TeacherMate+ rules.
  2. On first login or after reset, change your password when prompted.
  3. Review the TeacherMate+ Privacy Consent, tick the consent box, and type the required confirmation phrase. The sidebar and Change Password stay locked until this is done.
  4. If OTP is enabled, enter the code sent to your registered email.
  5. The first visit may show a quick tour. You may move through it or disable it for the next login.
  6. Signing in on a new device may close your older session.
  7. Faculty sessions time out after 1 hour of inactivity.
  8. If a password is incorrect, the Faculty Portal stays on the same welcome page and shows the error near the login form.
  9. Too many failed login attempts may temporarily lock the account.
These controls protect your account and student records. Use only your own faculty account.
Privacy, Data Protection, and Audit
  • Use only your own faculty account. Do not share your password.
  • Password rules, OTP, privacy consent, one-session login control, session timeout, and lockout help protect accounts.
  • Review student data only for your assigned classes.
  • Score, attendance, submission, correction, and reopen actions may be audited.
  • Handle printed or exported records according to school data privacy rules.
For the official privacy statement, refer to the NCBA Data Privacy Notice.
Frequently Asked Questions
Why can I not create an attendance session?

If the period is read-only, closed, locked, or already submitted, session creation is disabled. You can still select an existing session for review if one was created earlier.

Why are official grades hidden or not printable yet?

Admin can choose whether periodic grades are visible before submission. The official printout is available only after submission, and deadline-release settings may still hide period or final grades until the configured release point.

What should I do if the current active period is not the period I expected?

The active period is governed by admin settings and deadline rules. If a prior period is closed, open the current active period for encoding, or ask authorized admin users about reopen or correction options.

Can I still edit grades after submission?

Submitted gradebooks are protected. Use the correction or reopen process when changes are still required.

Until when can I mark a student as dropped?

Faculty DRP access depends on the school's configured cutoff period. In the usual setup, faculty may mark DRP through Pre-Final, but not after Pre-Final before the Final Exam period.

When can I print the Final Clearance?

You can print Final Clearance only after all accepted course assignments in the campus-term scope are COMPLETE. If any course is still incomplete, open Final Clearance to check the missing items, then finish the remaining submission or final-grade requirements first.

What happens if I do not create an activity for a grading component?

If the template requires that component, submission readiness may block submission because TeacherMate+ has no activity or attendance setup to compute that part of the grade. Create the needed activity, encode scores, then recompute or review Summary again.

What should I do if My Classes says the grading template is not assigned yet?

Do not start encoding grades for that class yet. Coordinate with the MIS Department so the correct grading template can be assigned to the course offering.

What should I do if the assigned grading template looks wrong?

Open the class grading-template page and use Report Template Issue if the button is available. The report goes to governance review and does not change grades immediately. If the button is not shown, coordinate with your academic head or MIS because template issue reporting is controlled by governance settings.

What should I do if a class in My Classes is not mine?

Do not encode grades or attendance for that class. Report it to your campus administrator, dean, or academic coordinator so the faculty assignment can be corrected.

Why can I not submit even though I encoded some scores?

Submission requires complete records for active students and required template items. Check Summary readiness for missing activities, attendance sessions, blank required records, or students that need the correct class-list status.

What should I do if the submission deadline already passed?

Finish encoding and submit as soon as possible. Overdue unsubmitted gradebooks remain open for completion, but they may appear in monitoring and non-compliance reports.

Why is a student missing from submission readiness?

Only active students are included in normal readiness checks. Students marked DRP, WITHDRAWN, INC, or removed from class may be excluded from active grading counts.

When should I use the Student Intervention Monitor?

Use it during the current active grading period, especially after scores are encoded. It is most helpful before the period closes, while there is still time to contact students and complete missing requirements.
