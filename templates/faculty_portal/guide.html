Part 1: Daily Workflow

Begin here before creating activities or encoding scores.

Recommended Daily Faculty Workflow
Daily Work Rhythm

A gentle reminder that the portal is meant to support routine class work, not create pressure.

Focused Checking

Reviewing structure, scores, and summary results before submission prevents avoidable corrections later.

Faculty Assignment Acceptance Rules
  • Every newly assigned class must be accepted first before you can open grading or class-list tools.
  • The pending-assignment card shows the response due date. Respond before the deadline so the assignment does not expire.
  • If there is a concern about the load, use Request Clarification and include a note for admin.
  • If the load should not be assigned to you, use Decline and explain the reason clearly.
  • If the assignment already expired, wait for admin to refresh the response window before responding again.
Good routine: check pending assignments first each time you log in, especially after load changes or at the beginning of a new term.
How to Respond to a New Assignment
  1. Open My Classes.
  2. Review the Pending Faculty Assignments section first.
  3. Read the course, section, schedule, and any admin instructions carefully.
  4. Review the Grading Template shown on the assignment or class card so you know the grading structure attached to that class.
  5. If the load is correct, click Accept Assignment.
  6. If the load needs discussion, enter your note and choose Request Clarification or Decline.
  7. After acceptance, the class becomes available for grading and class-list work.

Part 2: Encoding and Review

Set up activities correctly, then check attendance and summary before submission.

Creating Activities and Encoding Scores
  • Choose the Component first. Subcomponent and detail controls open only when the selected structure requires them.
  • Use short activity titles to avoid crowding the summary and printed grade book.
  • The Date field helps EduGradesPro keep the class record in proper activity order and supports audit clarity.
  • If the item uses Raw Score, the score cannot go beyond the activity total score.
  • If the item uses Direct Percentage, enter a percentage directly from 0 to 100.
  • Blank score fields remain unencoded. Clearing a previously saved score removes it for that activity.
Tip: If you only want to encode one or two students first, enter values only for those students and leave the others blank.
Step-by-Step: Create Grade Activity
  1. Open My Classes and accept any pending assignment first if the class is newly assigned. Watch the response due date on the pending card so the load does not expire before you acknowledge it.
  2. Click Template on the class card whenever you want to review the assigned grading structure before encoding activities or scores.
  3. If there is a problem with the load, use the clarification or decline action with a note to admin. Once an assignment expires, only admin can refresh the response window.
  4. Choose class -> choose period -> click the Activities icon.
  5. Select Component first.
  6. Select Subcomponent only if the selected component requires it.
  7. Select Detail only if the selected subcomponent requires it.
  8. Enter a short Activity Title (ex: Q1, R1, A1, AC1).
  9. Enter Total Score (for direct percentage items, system uses 100).
  10. Set Date using the date picker.
  11. Click Save Activity.
Step-by-Step: Encode Scores
  1. From the Activities table, click Encode Scores on the target activity.
  2. Enter score values only for students to encode now (leave blank if not yet ready).
  3. Click Save Scores.
  4. Verify the Encoded count on the Activities list.
Step-by-Step: Update Existing Activity
  1. Click Edit on the activity row.
  2. Update component mapping/title/total/date as needed.
  3. Click Update Activity.
  4. Re-check summary results after update.
Step-by-Step: Delete Activity
  1. Click Delete on the target activity row.
  2. Confirm deletion.
  3. Review the summary to ensure expected values after deletion.
Guardrails (Activities and Scores)
  • You cannot save scores above the allowed max (total score for raw-score items, 100 for direct percentage).
  • The Activities page and the Encode Scores page now include a Quick Jump strip so you can move directly to Attendance, Summary, or Who Viewed without returning to the period card first.
  • If the period is Submitted or Locked, normal editing is blocked.
  • During correction window, editing is scope-limited to approved correction items only.
  • Activity deletion is blocked while approved correction window is active.
  • If you type score values and try to leave the Encode Scores page without saving, EduGradesPro now warns that unsaved encoded data will be lost.
Attendance and Summary (Step-by-Step)
Step-by-Step: Attendance
  1. Open period card -> click Attendance icon.
  2. Create or select an attendance session (date/title).
  3. Set attendance status per student.
  4. Click Save Attendance.
Step-by-Step: Summary Review
  1. Open period card -> click Summary icon.
  2. Review component-level and overall period grades.
  3. Check submission readiness indicators (coverage, missing records).
  4. Use Print Grade Book for pre-submission verification.
  5. Submit only when ready.
Guardrails (Attendance and Summary)
  • Submitted or locked periods are view-only for normal attendance/summary edits.
  • The Attendance, Summary, and Who Viewed pages now include the same Quick Jump strip so faculty can move between related grading pages with fewer clicks.
  • If a period is closed by the active grading period policy after deadline, the Attendance and Summary pages remain accessible for review, but they open in read-only mode.
  • Submission is blocked if no encoded grade/attendance exists for active students.
  • If some active students have no records, system shows warning before final submission.
  • Official computed period grades and final grade follow the tenant grading policy of the class. By default they remain visible, but Admin may still restrict their release until the configured deadline.
  • The Who Viewed icon on the period card remains available even when the period is closed, so faculty can still review grade book monitor history for that class period.
If a value looks unexpected, review the activity setup, score entry method, total score, and class list status before submitting.
Grade Prediction and What-If Simulation
  • Prediction is unofficial and read-only. It never changes the official gradebook.
  • EduGradesPro uses the same assigned grading template structure and current encoded data to estimate outcomes.
  • The primary projected grade follows the default assumption configured by admin for your tenant.
  • If enabled, the system can also show best-case, worst-case, and target-needed guidance.
  • If enabled for your role, the what-if simulator lets you test remaining performance scenarios before actual encoding.
  • The Prediction page now includes a dedicated interpretation guide so faculty can review the methodology, Base 50 transmutation, period-grade and final-grade computation, the factors used in each column, and sample scenarios before relying on the values.
  • The page can also show the average still needed across the remaining final periods to reach a passing final grade.
  • The Faculty Portal also includes a Student At-Risk Monitor that groups students by class and period so you can see who needs attention first.
Treat prediction as planning support only. Official grades still depend on actual encoded scores, submission status, and approved governance actions.
How to Use the Prediction Page
  1. Open My Classes, choose the class, then open the period card.
  2. Click the Prediction icon.
  3. Open How Prediction Works when you need the full explanation of each column and sample scenarios.
  4. Review current projection, coverage, remaining items, and at-risk indicators.
  5. Open the At-Risk Monitor from the sidebar when you want a class-by-class list of students who are currently below the passing line.
  6. If what-if is enabled, select a student and enter an estimated remaining performance percentage.
  7. Use Refresh Prediction after major score changes if you want a fresh snapshot immediately.

Part 3: Submission and Corrections

Use these controls only when your records are complete and policy conditions are met.

Submission Rules
  • Submitted grading periods become view-only for normal editing.
  • EduGradesPro blocks submission if there are no encoded grade or attendance records for active students.
  • If any ACTIVE student still has blank required grade or attendance records in the visible summary columns, EduGradesPro blocks submission until the blanks are completed or the status is updated to DRP/W/INC.
  • The Summary readiness area now uses colored cards for ACTIVE, complete records, missing records, coverage, DRP, W, and INC. Pass/Fail cards follow the current passing-threshold rule and normally appear with the official period grade; they are delayed only when Admin explicitly enables the post-deadline official-grade release restriction. EduGradesPro now resolves that threshold in this order: matched Tenant Grading Profile override, assigned grading-template threshold, tenant default setting, then fallback 75.00.
  • The overall FINAL GRADE appears only on the Final period Summary page. On that Final page, EduGradesPro also shows PRELIM GRADE, MIDTERM GRADE, and PRE-FINAL GRADE columns before the Final Exam so faculty can review the grade trail in one place.
  • EduGradesPro computes the overall FINAL GRADE using the full configured period count. If earlier periods already have grades but later periods are still blank, the missing periods still count in the divisor instead of being ignored.
  • EduGradesPro now shows a visible Current Active Grading Period banner on the Faculty Dashboard, on My Classes, and inside the class period page so you can see which period the campus is currently focused on.
  • When an active grading period is configured, non-active period cards are closed by policy for normal encoding. Attendance and Summary remain open as read-only review pages, while activity/score changes still require the period to become active, be reopened, or use an approved correction window.
  • The My Classes page now includes a dedicated Final Clearance action area so faculty can preview their campus-term completion status and generate the official clearance PDF without opening the period page first.
  • Each generated clearance includes a printed QR code, Reference No., and Verification Code so authorized NCBA personnel can validate the paper copy from the Admin Portal.
  • EduGradesPro also shows a visible grade submission deadline banner on the Faculty Dashboard, on My Classes, and inside the class period page so you can track the active period deadline more easily. If a deadline exists but belongs to a different campus or term scope, or uses a period code that does not match your class template, the banner will say so directly.
  • The Faculty Dashboard now also includes an Incomplete Students KPI so you can quickly see how many active-class rows are currently marked INC.
  • Always review the printed sheet or on-screen summary before finalizing.
Grade Corrections and Reopen Governance
System Request Mode

Use the in-portal correction request if your school allows online filing and approval tracking for grade changes.

Manual Only Mode

Use the paper route when the tenant policy requires manual approval and admin reopen processing outside the portal.

System Request Mode (SYSTEM_REQUEST)
  1. Submit period first.
  2. Open Correction Requests from Summary/Period screen.
  3. Select one or more students, or choose the entire class, then choose the affected grading items.
  4. Review the auto-loaded original values and enter only the corrected values.
  5. File the request with justification.
  6. Wait for governance approval route (for example: Coordinator -> CAO).
  7. After final approval, EduGradesPro copies the approved corrected values directly into the gradebook and recomputes the submitted period automatically.
  8. No additional faculty finalize step is required for this direct score-correction petition flow.
  9. If your school enables the official correction report feature, the approved request also provides an official PDF for registrar reference showing campus applicability, official grade original/corrected values, and approval summary (supporting files remain in-system). The PDF opens in a new browser tab for preview/print/download.
  10. If your school enables submission notifications, EduGradesPro also emails the configured approver roles, such as CAO and college dean, using an NCBA-branded card that includes petitioner and period name details.
Manual Mode (MANUAL_ONLY)
  1. Faculty prepares and submits paper correction form.
  2. Paper form is approved by authorized academic officers.
  3. Final approver (or authorized admin) reopens the class period in Admin Portal.
  4. Faculty performs approved correction updates.
  5. Faculty re-submits period.
Guardrails (Corrections)
Before Deadline

If tenant policy allows faculty self-reopen, a submitted period may be reopened directly by the teacher before the deadline. Otherwise, the correction request workflow applies.

Manual-Only Schools

If the tenant is set to MANUAL_ONLY, in-portal correction request filing is disabled. Faculty should follow paper approval flow and wait for authorized admin reopen action.

After Deadline

Reopen and correction actions are governed. The faculty member should use the correction request process and wait for authorized review.

Approval Route

Approval route is configured by admin based on the requesting faculty department. Your school may use one-step final approval (for example, CAO) or two-step review (for example, Coordinator then CAO).

Original vs Corrected Value

The correction request grid already shows the current gradebook value. Faculty should enter only the approved replacement value for each selected row.

Audit Trail

Submissions, reopen actions, correction requests, approvals, and follow-up actions are logged for monitoring and accountability.

Part 4: Class List, Account Help, and Privacy

Manage class status carefully and follow security/privacy guidance.

Class List Rules: Movement, ACTIVE, DRP, W, and INC
  • ACTIVE means the student remains part of the grading coverage.
  • Remove from Class is for schedule movement. Use it when the student transferred to another class/section and should no longer appear in this class master list.
  • DRP means the student dropped this particular class and should no longer be treated as an active graded student for the class.
  • W means the student withdrew from the term and is also excluded from normal active grading coverage.
  • INC means the class record is incomplete and is also excluded from normal active grading coverage.
  • Use the class list carefully before submission because class list status affects readiness, summary interpretation, and final grade handling.
EduGradesPro now shows a visible Status Legend on the class list page so you can immediately see what ACTIVE, DRP, W, and INC mean before updating a row.
Step-by-Step: Handle Student Movement or DRP/W/INC
  1. Open class -> go to Class List.
  2. Find the student row.
  3. Use the line number at the start of each row if you want a faster visual reference while checking the class list.
  4. If the student only changed schedule, click the small x beside the student number, then type remove to confirm.
  5. If the student truly dropped the class, withdrew from the term, or needs an incomplete class record, use the status dropdown and choose DRP, W, or INC.
  6. Click Save Status when updating DRP/W/INC.
  7. Recheck Summary readiness after status update.
Guardrail: removed, DRP, W, and INC students are excluded from normal active grading coverage and submission readiness counts.
Faster lookup: when adding a student to the class list, type the student number or the student's last name and first name first so EduGradesPro narrows the student dropdown before you click Save.
Readability: the class list now shows the last name in uppercase and the first name in proper case so faculty can scan names more comfortably.
Archived Classes Explained
  • Active Classes = current workload under active AY/Term and non-archived offerings.
  • Archived Classes = offerings outside current active AY/Term scope or explicitly archived offerings.
  • Archived classes are kept for historical reference and monitoring.
How to View Archived Classes
  1. Open My Classes.
  2. Switch to Archived tab/filter.
  3. Open class card if review access is allowed by policy.
If You Lost Your Password
  • Go to the Faculty Portal sign-in page and use the Forgot Password option.
  • Enter your official faculty email address that is registered in EduGradesPro.
  • Check your email inbox for the password reset message from the system.
  • If the email does not arrive, check your spam or junk folder first.
  • If your account is temporarily locked after too many failed sign-in attempts, wait for the lockout period to end or use the reset option if needed.
  • If you still cannot reset your password, contact your campus administrator, registrar support, or the assigned EduGradesPro operations team.
For security, faculty members should not request passwords from co-teachers or share login credentials. Use the reset process or ask the authorized support team for assistance.
User Account Security
  1. Use a strong password that satisfies EduGradesPro password complexity rules.
  2. On first login or after an issued password reset, complete the forced password change before portal access continues.
  3. Review and accept the current EduGradesPro Privacy Consent before using the portal.
  4. EduGradesPro enforces single-device session control, so signing in on a new device may close your older session automatically.
  5. Faculty portal sessions now time out after 1 hour. Active use refreshes the session window, but long inactivity will require you to sign in again.
  6. Repeated failed sign-in attempts may trigger a temporary login lockout for your protection.
These controls protect your account, student records, and the audit trail. Use only your own faculty account and keep credentials private.
Privacy, Data Protection, and Accountability
  • Use only your assigned faculty credentials. Do not share your password with anyone.
  • Password complexity validation, forced password change, privacy consent, single-device session enforcement, a 1-hour session timeout, and temporary login lockout are part of the account security flow.
  • Review student data only for officially assigned classes.
  • Changes in scores, attendance, submissions, corrections, and reopen actions are monitored for governance and audit purposes.
  • Respect institutional data privacy requirements when viewing, printing, or discussing student records.
For the official privacy statement, refer to the NCBA Data Privacy Notice.
