Creating Activities and Encoding Scores
  • Choose the Component first. Subcomponent and detail controls open only when the selected structure requires them.
  • Use short activity titles to avoid crowding the summary and printed grade book.
  • The Date field helps EduGradesPro keep the class record in proper activity order and supports audit clarity.
  • If the item uses Raw Score, the score cannot go beyond the activity total score.
  • If the item uses Direct Percentage, enter a percentage directly from 0 to 100.
  • Blank score fields remain unencoded. Clearing a previously saved score removes it for that activity.
Tip: If you only want to encode one or two students first, enter values only for those students and leave the others blank.
How the Summary Helps You
  • The summary mirrors the configured grading template hierarchy for the selected period.
  • Activity averages and class standing values are shown separately so faculty can trace where a result came from.
  • The print button produces a compact grade-book style submission sheet for formal review and filing.
  • The summary also shows submission readiness, including active students with missing records.
If a value looks unexpected, review the activity setup, score entry method, total score, and class list status before submitting.
Submission Rules
  • Submitted grading periods become view-only for normal editing.
  • EduGradesPro blocks submission if there are no encoded grade or attendance records for active students.
  • If some active students still have missing records, the system warns you before submission so you can review the class list carefully.
  • Always review the printed sheet or on-screen summary before finalizing.
Corrections and Reopen Governance
Before Deadline

If tenant policy allows faculty self-reopen, a submitted period may be reopened directly by the teacher before the deadline. Otherwise, the correction request workflow applies.

After Deadline

Reopen and correction actions are governed. The faculty member should use the correction request process and wait for authorized review.

Audit Trail

Submissions, reopen actions, correction requests, approvals, and follow-up actions are logged for monitoring and accountability.

Class List Status: ACTIVE, DR, and W
  • ACTIVE means the student remains part of the grading coverage.
  • DR means the student is dropped and should no longer be treated as an active graded student for the class.
  • W means the student is withdrawn and is also excluded from normal active grading coverage.
  • Use the class list carefully before submission because class list status affects readiness, summary interpretation, and final grade handling.
If You Lost Your Password
  • Go to the Faculty Portal sign-in page and use the Forgot Password option.
  • Enter your official faculty email address that is registered in EduGradesPro.
  • Check your email inbox for the password reset message from the system.
  • If the email does not arrive, check your spam or junk folder first.
  • If you still cannot reset your password, contact your campus administrator, registrar support, or the assigned EduGradesPro operations team.
For security, faculty members should not request passwords from co-teachers or share login credentials. Use the reset process or ask the authorized support team for assistance.
Privacy, Data Protection, and Accountability
  • Use only your assigned faculty credentials. Do not share your password with anyone.
  • Review student data only for officially assigned classes.
  • Changes in scores, attendance, submissions, corrections, and reopen actions are monitored for governance and audit purposes.
  • Respect institutional data privacy requirements when viewing, printing, or discussing student records.
For the official privacy statement, refer to the NCBA Data Privacy Notice.
