Prepare Case-based sections before opening contributions

For Departmental Automatic exams, enable Structured Case/Scenario Exam Lifecycle in Configurable Features and configure the blueprint before first Open. Section titles, order and exact quotas freeze when contributions open.

Agree on a common Linked MCQ count per Case within each section that divides its quota. For example, a 20-item section can use four 5-question Cases. This is preparation guidance, not a required Case size. Coordinate the pool with the configured campus allocation and Faculty contribution quotas.

Mixed preparation is supported: whole Cases plus standalone MCQs may fill a section's exact quota. Every linked MCQ counts as one item; the narrative does not count. Automatic generation moves only whole blocks within a section and preserves saved Linked Question order. Complete and Final Submit valid Cases before the deadline. An unusable Case is excluded in full with a warning; generation continues only when remaining whole units meet every hard requirement. Difficulty is a preferred target, reported beside the actual mix.
