How cycle defaults work. These are the normal values for eligible grouped course examinations. Course overrides are intentional exceptions. Changes propagate only to eligible never-opened Draft rows; opened and historical configurations remain preserved. One grouped examination is shared across all listed campuses where the course is offered.
Example: If the cycle contribution deadline is August 15 at 5:00 PM, eligible grouped courses use it by default. If one grouped course must close on August 14, set a course override. Removing the override restores August 15. Without a cycle deadline, the course shows NOT CONFIGURED and cannot be opened.
