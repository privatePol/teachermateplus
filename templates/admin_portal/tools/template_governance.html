Use this page to decide who controls the grading-template lifecycle. Phase 1 is the role matrix for the existing actions. Phase 2 is the optional sequential workflow chain that adds step-by-step review and approval.
Recommended Setup: New Grading Template Issuance
Use this if your desired governance flow is: Draft and Submit (SuperAdmin) -> Review (AC) -> Approval and Publishing (CAO).
Step 1. Phase 1 - Role Matrix
  • Draft Roles: SUPER_ADMIN
  • Submit for Approval Roles: SUPER_ADMIN
  • Approval Review Roles: AC, CAO
  • Publish Roles: CAO
Step 2. Phase 2 - Sequential Steps
  • Use a sequential template approval chain: ON
  • Template Review: AC
  • Final Approval: CAO
Step 3. Workflow Safeguards
  • Require approval before publish: ON
  • Allow same user to submit and review: OFF
  • Allow same user to review and final-approve: OFF
  • Allow same user to review and publish: ON only if CAO will both final-approve and publish
Recommended Setup: Hotfix
Hotfix is for changes to an already published template. It is separate from new-template review. Use this if your desired governance flow is: Hotfix Request (SuperAdmin) -> Hotfix Review (AC) -> Hotfix Final Apply (CAO).
Step 1. Phase 1 - Role Matrix
  • Hotfix Request Roles: SUPER_ADMIN
  • Hotfix Review and Apply Roles: AC, CAO
Step 2. Phase 2 - Sequential Steps
  • Use a sequential hotfix workflow: ON
  • Hotfix Review: AC
  • Hotfix Final Apply: CAO
Step 3. Workflow Safeguards
  • Allow same user to request and apply a hotfix: OFF
  • Allow same user to review and final-apply a hotfix: OFF
  • Keep hotfix duty separated from request duty to reduce abuse risk on live templates.

Recommended NCBA Starting Point
  • Draft, Submit, Publish, and Hotfix Request: keep these under the template steward roles only.
  • Phase 2 Sequence: use Template Review for Dean/AC scrutiny, then Final Approval for CAO.
  • Hotfix Sequence: use Hotfix Review for academic scrutiny, then Hotfix Final Apply for CAO or steward-controlled final execution.
  • Keep all same-user safeguard switches off unless the institution formally accepts combined duties.
