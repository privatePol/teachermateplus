Grading Template Setup Guide

Use this guide to create a grading template, choose how scores will be entered, and assign the finished setup to the correct courses.

1. Before You Start

Prepare the approved grading formula before entering anything in TeacherMate+.

Menu: Admin Portal → Grading → Grading Templates

Write down the approved grading setup

  • List the grading periods in the correct order.
  • List the main grading parts and their percentages for each period.
  • Mark which main part is the period exam.
  • List the activity groups faculty members may use.
  • Confirm whether Participation/Output uses percentage weights or equal averaging.

Choose Add Template or Duplicate

Click Add Template when the grading setup is completely new.

Use Duplicate when an existing template is already close to what you need. The copy starts as a draft and keeps the source template's Department Visibility. It does not copy course assignments, faculty activities, grades, submissions, locks, corrections, or grading profiles.

Choose who can see and govern the template: Use All Departments for a tenant-wide template. Use Selected Departments when only authorized admins assigned to specific departments should see, review, approve, publish, duplicate, calculate, or hotfix it. A selected-department template requires at least one department. Superadmin can still access every template.
Important: Finish and test the template before assigning it to courses. If faculty members are already using a published template, do not edit it directly. Use the approved Hotfix process for an urgent change.

2. Build the Template Structure

Build the grading setup from the period down to the activity type.

Template→Period→Component→Subcomponent→Detail
  1. Click Add Template. Enter a unique code and a clear name.
  2. Enter the usual Base-50 value. Add a passing grade only when this template has its own approved passing rule.
  3. Choose Department Visibility. If you choose Selected Departments, select every department allowed to view and govern this template.
  4. Save the template, find it in the list, and click Builder.
  5. Click Add Period. Add PRELIM, MIDTERM, PRE-FINAL, FINAL, or the approved periods used by your school. Use the sequence number to place them in the correct order.
  6. Add the main Components inside each period. Examples are Class Standing and Period Exam. The component percentages for one period should total 100%.
  7. Check Exam component only for the main exam part. TeacherMate+ uses this checkbox to identify the exam.
  8. Add Subcomponents under a component. Examples are Quizzes and Participation/Output.
  9. Add Details when faculty activities need smaller groups. Examples are Recitation, Assignment/Activities, and Oral Presentation.
  10. Keep only approved and usable rows active. Faculty members cannot normally use inactive rows.
Example structure
  • Period: MIDTERM
  • Component: Class Standing
  • Subcomponent: Participation/Output
  • Details: Recitation, Assignment/Activities, Oral Presentation
How the percentages work: A component percentage shows its share of the period grade. A subcomponent percentage shows its share of the component. Detail percentages are used only when Weighted Details is selected.

3. Choose the Score Entry Method

This setting tells TeacherMate+ how to read the score entered by faculty.

MethodSimple meaningExampleWhen to use it
Inherit Parent Rule Use the same score rule as the level above it. If Class Standing uses Raw Score, a detail set to Inherit also uses Raw Score. Use this for most subcomponents and details. Choose a different method only when the approved policy requires it.
Raw Score (Base-50) Faculty enters the points earned and the highest possible score. TeacherMate+ applies the approved Base-50 formula. For a 50-point quiz, faculty enters 42 out of 50. TeacherMate+ computes the grade. Use this for the normal TeacherMate+ and NCBA grading process.
Direct Percentage Faculty enters a percentage that is already final. TeacherMate+ uses it as entered and does not apply Base-50. If an approved result is already 85%, faculty enters 85. Use this only when the approved school policy specifically requires direct percentage entry. Do not select it only because an activity has a total of 100 points.
Recommended setup: If your school uses Raw Score Base-50 for all activities, select it on the main component. Set the lower levels to Inherit Parent Rule. Do not mix methods unless the academic policy clearly requires it.

4. Choose Weighted Details or Average Activities

This setting decides how activities under a subcomponent are combined.

SettingSimple meaningUse of detail percentagesExample
Weighted Details Each detail has its own percentage weight. The detail percentages are used. They must follow the approved setup and total 100%. Participation/Output is 60% of Class Standing. Inside it: Recitation 20%, Assignment 30%, and Oral Presentation 50%.
Average Activities All active activities are averaged equally. TeacherMate+ does not use the detail percentages in the calculation. If faculty creates R1, R2, Assignment 1, Seatwork 1, and Oral 1, all five activities have an equal share in the average.

Should I enter a weight when using Average Activities?

Yes. The form still requires a number. Enter positive percentages that total 100% so the setup is complete and easy to review.

For three details, you may enter 33.34%, 33.33%, and 33.33%. TeacherMate+ will ignore these detail percentages while Average Activities is selected.

Which weight still matters?

The Participation/Output subcomponent percentage still matters. If Participation/Output is 60% of Class Standing, keep it at 60%. Only the activities below it are averaged equally.

Participation/Output submission rule: When Average Activities is selected, faculty must create at least one active Participation/Output activity before submitting grades. Unused or inactive detail rows will not block submission. Scores required for active activities must still be completed. A saved score of zero is valid and is not treated as missing. When Weighted Details is selected, the existing strict checks for the weighted setup still apply.
Do not change this after grading has started without approval. Switching between Weighted Details and Average Activities can change computed grades. For a published template already used by faculty, use the approved Hotfix process and review the affected unsubmitted gradebooks.

5. What to Do After Building the Template

Test, approve, publish, and assign the template before faculty uses it.

  1. Open Builder. Check the periods, percentages, activity groups, score rules, active rows, and exam checkbox.
  2. Return to Grading Templates and open Test Calculator. Try high, average, low, zero, and missing-score examples.
  3. Submit the draft for approval. Complete the required review steps. Publish it only after approval.
  4. Decide whether this template needs a Tenant Grading Profile. Its main purpose is to tell TeacherMate+ how the grading periods will be combined to compute the official final grade for a campus, department, program, course group, or other approved scope.
  5. Open Grading → Course Template Assignments. Assign the published template to the correct courses and starting term.
  6. Create a Course Base Value Override only when one course has an approved exception to the normal Base-50 rule.
  7. Check that all courses have the correct template. Open one sample faculty class and confirm the setup before encoding begins.

6. When to Create a Tenant Grading Profile

A Tenant Grading Profile controls how period grades are combined to compute the official final grade for a specific school group.

Menu: Admin Portal → Grading → Tenant Grading Profiles
Main purpose: The profile tells TeacherMate+ whether the official final grade should average all active grading periods or use approved percentage weights for selected periods. It may also provide the correct template, Base-50 default, passing grade, and period-grade rule for the same group.
Create one whenA campus, department, program, course group, course, or term type needs an explicit approved final-grade rule or another grading setting that differs from the general setup.
ExampleCreate a profile when the BSA program uses a specific published template and an approved final-grade formula for Regular or Summer terms.
One per template?No. One broad profile may serve many courses when they use the same approved rules. Create another profile only when the school group or grading rule is different.
Which profile is used?TeacherMate+ uses the closest matching active profile. For example, a profile for one course is more specific than a general campus profile.
If no profile matchesTeacherMate+ still computes the final grade. It averages every active grading period in the published template used by the course. This fallback is correct only when equal averaging is the approved school rule.
Regular and Summer example:
  • 1st and 2nd Semester: If both use the same rules, one Regular template may contain PRELIM, MIDTERM, PRE-FINAL, and FINAL. The final grade is the average of the four period grades.
  • Summer: Create a separate Summer template containing MIDTERM, PRE-FINAL, and FINAL. The final grade is the average of the three period grades.
  • Mark 1st and 2nd Semester terms as Regular. Mark the Summer term as Summer.
  • For explicit governance, create a Regular profile and a Summer profile for the department or other approved scope. Set both to Average All Active Template Periods.
  • Assign the correct published template to the correct courses and terms through Course Template Assignments. A course assignment for the exact term is checked before a profile is used to choose the template.
Important: Do not use the four-period Regular template for Summer if PRELIM must not be included. Average All Active Template Periods includes every active period in the template.
Avoid conflicting profiles: Do not create several active profiles for the same group unless their purpose and priority are clear. After saving, test one actual class to confirm that it receives the correct profile and template.

7. When to Use Course Base Value Overrides

Use this only when one course has an approved exception to the usual Base-50 rule.

Menu: Admin Portal → Grading → Course Base Overrides

Use it when

  • A specific course has an approved base value different from the usual Base-50 value.
  • The approving academic office has recorded the reason.
  • You know whether the exception starts in one term or applies generally to that course.

Do not use an override for

  • Changing one student's score or grade.
  • Fixing an incorrect grading-template weight.
  • Choosing Weighted Details versus Average Activities.
  • A test, temporary change, or exception without approval.
Example: Most courses use Base-50. One approved course must use Base-40. Create a Course Base Value Override for that course only.
Which Base value is used first? TeacherMate+ checks the Course Base Value Override first. If none exists, it checks the matching Tenant Grading Profile, then the Course, then the Template. If none has a value, TeacherMate+ uses 50. Because the course override comes first, use it only for a real approved course exception.

8. Final Readiness Checklist

Complete this checklist before faculty creates activities or enters scores.

Check the template

  • The correct school, code, name, Base-50 value, and passing grade are shown.
  • The periods are in the correct order.
  • Only approved and usable rows are active.
  • Component weights total 100% per period.
  • Subcomponent weights match the approved grading formula.
  • The correct main component is marked as the exam.
  • Participation/Output uses the approved setting: Weighted Details or Average Activities.

Check before faculty use

  • The Test Calculator results match the approved sample grades.
  • The required approvals are complete and the template is published.
  • The final-grade rule is confirmed: TeacherMate+ will either use the matching Tenant Grading Profile or average all active periods when no profile matches.
  • Regular and Summer courses use templates with the correct active grading periods.
  • The correct courses and starting term are assigned.
  • A Course Base Value Override exists only for an approved exception.
  • One sample faculty class shows the expected grading setup.
